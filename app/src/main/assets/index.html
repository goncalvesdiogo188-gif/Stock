Partilhar entre telemóveis

Para o stock ser igual em todos os telemóveis, ligue-os à mesma base de dados (Firebase, gratuita). Sem Internet a app continua a funcionar e envia as alterações quando a rede voltar.

Primeiro telemóvel: cole o endereço da base de dados. Outros telemóveis: cole a ligação que o primeiro enviar (não o endereço da base de dados).

Como criar a base de dados (só uma vez)
  1. Abra console.firebase.google.com com uma conta Google e toque em Criar projeto (qualquer nome; pode desligar o Google Analytics).
  2. No menu, abra Realtime Database e toque em Criar base de dados. Escolha a localização Bélgica (europe-west1) e modo bloqueado.
  3. No separador Regras, apague tudo, cole as regras abaixo e toque em Publicar. 
    {
  "rules": {
    ".read": false,
    ".write": false,
    "lojas": {
      "$codigo": {
        ".read": true,
        ".write": true
      }
    }
  }
}
  4. No separador Dados, copie o endereço que aparece em cima (termina em firebasedatabase.app ou firebaseio.com) e cole-o aqui.
  5. Toque em Ligar e depois em Enviar ligação pelo WhatsApp para os outros telemóveis.

Para ligar outro telemóvel, envie-lhe esta ligação e cole-a lá em “Partilhar entre telemóveis”. Quem tiver a ligação pode ver e alterar o stock.
